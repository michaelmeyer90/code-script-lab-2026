## Getting Started

First clone the repository and move into its directory:

```bash
git clone https://github.com/michaelmeyer90/code-script-lab-2026.git
cd REPO
```

You can open an HTML project directly in your browser. Alternatively, start a local server if you prefer to work through a browser-based development flow:

```bash
python -m http.server 8000
```

Open `http://localhost:8000/` in your browser, then choose the experiment you want to view. To compare edits against the original files, place your modified copies in a separate working directory.
